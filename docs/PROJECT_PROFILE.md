# Профиль проекта

- Сайт: https://plugins-store.ru
- Репозиторий: `Pashtet221/reboot`
- Theme: `reboot`
- Назначение репозитория: WordPress-тема + Codex Bridge client в одном workspace
- Тип записи плагинов: `wp-plugins`
- Тип записи услуг: `service`
- Управление опубликованным WordPress: `scripts/wp`
- SEO: Rank Math, если активен на сайте
- ACF: использовать фактическую конфигурацию живого сайта
- Разрешённые директории темы: корень темы, `assets/`, `inc/`, `plugins/` и другие файлы этого репозитория
- Запрещённые изменения без прямого указания: WordPress Core, WooCommerce Core, сторонние плагины
- Источник истины для контента/ACF/SEO: опубликованный WordPress через Bridge
- Источник истины для PHP/CSS/JS и шаблонов: этот репозиторий

Перед любой задачей, которая требует данных сайта, сначала выполнить `scripts/wp health`, затем получить нужные объекты через `scripts/wp`.
