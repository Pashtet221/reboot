# Правила проекта plugins-store.ru

Этот репозиторий одновременно содержит активную WordPress-тему сайта plugins-store.ru и инструменты Codex для работы с опубликованным WordPress через `scripts/wp`.

## Перед началом работы
- Выполни `scripts/wp health`.
- Прочитай `docs/PROJECT_PROFILE.md`.
- Если задача связана с существующей страницей, записью, плагином, услугой, SEO, ACF или другим объектом WordPress — сначала прочитай актуальный объект через `scripts/wp`, а не делай вывод только по файлам темы.

## Источники истины
- PHP/CSS/JS/шаблоны и структура фронтенда: файлы этого репозитория.
- Опубликованный контент, записи, ACF, SEO и данные WordPress: живой сайт через `scripts/wp`.
- Если локальные предположения расходятся с опубликованным WordPress, сначала зафиксируй расхождение и используй фактические данные сайта.

## Изменения
- Файлы темы разрешено изменять напрямую в репозитории.
- Контент WordPress изменяй через `scripts/wp`.
- Перед изменением WordPress-объекта всегда сначала прочитай его текущее состояние.
- После изменения обязательно проверь результат повторным чтением объекта и, когда это относится к фронтенду, визуальной проверкой.
- Не меняй WordPress Core, WooCommerce Core и сторонние плагины без прямого указания.

## Скриншоты и медиа
- Для скриншотов внешних сайтов используй `scripts/wp capture`.
- Для кейсов предпочитай WebP, ширину до 1600 px, осмысленные filename/title/alt.
- Если нужен отдельный блок страницы, используй `--selector`; для мобильного вида — `--mobile`.
- После `capture` используй возвращённый `gutenberg_block` или `media.id`/`media.url` при создании и обновлении контента.

## Безопасность
- Никогда не сохраняй и не коммить логины, Application Password, API-ключи и другие секреты.
- Переменные подключения должны приходить из окружения: `WORDPRESS_URL`, `WORDPRESS_USERNAME`, `WORDPRESS_APP_PASSWORD`.
- Файлы `.env` должны оставаться вне Git.
